# 留一点空间，给思考。

欢迎使用 **墨页 Inkdown**。一个轻巧、安静的 Markdown 阅读与编辑空间。

不需要账号，也不需要网络。打开一份文档，从这里开始。

## 为阅读而留白

Markdown 让你专注内容，墨页让内容自然呈现。点击左侧的 **打开文件夹** 整理你的文档，或将 `.md` 文件直接拖入窗口。

> 简单，是把复杂留给工具，把清晰留给自己。

## 从阅读，到书写

点击右上角 **编辑**，在源码与预览之间自由切换。你的文档始终保存在自己的电脑上。

| 想做什么 | 快捷键 |
| :--- | :--- |
| 打开文档 | `Ctrl + O` |
| 打开文件夹 | `Ctrl + Shift + O` |
| 新建文档 | `Ctrl + N` |
| 保存 / 另存为 | `Ctrl + S` / `Ctrl + Shift + S` |
| 阅读 / 编辑 | `Ctrl + E` |
| 查找内容 | `Ctrl + F` |
| 关闭标签 | `Ctrl + W` |

### 一份小小的清单

- [x] 找一个舒服的阅读位置
- [x] 把想法写下来
- [ ] 完成今天的第一篇笔记

## 代码，也可以很好读

```typescript
interface Thought {
  title: string;
  worthKeeping: boolean;
}

const today: Thought = {
  title: '让想法慢慢成形',
  worthKeeping: true,
};
```

## 让公式与图表说话

行内公式 $E = mc^2$ 可以自然地融入文字。独立公式也同样清晰：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$
